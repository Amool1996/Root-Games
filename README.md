# 🌽 Amazing Roots! — Root Science Games for Kids

Three browser games that teach kids (K–5) about plant roots, built for the
CAFNR Showcase outreach booth (Division of Plant Science & Technology).

## 🎮 The games

| Game | What kids learn |
|------|-----------------|
| **Grow Your Root!** | Steer a growing root through soil — dodge rocks, collect water and N-P-K nutrients. Roots actively *forage* underground. |
| **Label the Root!** | Drag labels (Skin/epidermis, Sponge/cortex, Water Pipes/xylem, Food Pipes/phloem) onto a maize root cross-section. |
| **Farm Boss!** | Run a farm on a $100 budget from field prep to harvest. Pick seeds by their *root traits*, survive drought, storms and disease, and try to make a profit. Daily leaderboard included. |

## ▶️ How to play

**Online:** open the GitHub Pages link for this repository (see the About panel on the right).

**Offline (booth mode):** download `amazing-roots-games.html`, double-click it to open
in any browser, and press **F11** for fullscreen. No internet needed — everything
(graphics, sounds, leaderboard) lives in that one file.

Works with mouse, keyboard, and touchscreens.

## 🛠️ Tech

A single self-contained HTML file — no libraries, no build step, no server.
Canvas for the root maze, SVG drag-and-drop for the anatomy game, and
`localStorage` for the Farm Boss leaderboard.
