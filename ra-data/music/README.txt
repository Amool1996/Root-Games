ROOT RACE — music
=================

The game already has music on every screen, generated by the browser itself
(no files needed, works offline):

  title    bouncy and bright            (title screen)
  story    soft music box               (Rooty's Story - drops low while she talks)
  wheel    carnival oom-pah             (field wheel; the spin ticks and lands with a fanfare)
  design   curious, thinking            (picking the six cards)
  grow     rising arpeggios             (the roots growing; each drink pops)
  party    celebration                  (score, name entry, leaderboard)

The speaker button at the top right mutes everything, and remembers the choice.

Browsers only allow sound after the first tap, so the music begins with the
first touch on the title screen. That is normal.


TO USE REAL MUSIC INSTEAD
-------------------------
Put MP3 files in THIS folder and create a file here called  manifest.js  that
lists them, like this (leave out any you don't have - those keep the built-in
loop):

    window.RA_MUSIC = {
      title:  "title.mp3",
      story:  "story.mp3",
      wheel:  "wheel.mp3",
      design: "design.mp3",
      grow:   "grow.mp3",
      party:  "party.mp3"
    };

Tracks loop automatically and duck under the narration. Use music you have the
right to use at a public event: your own recordings, or tracks whose licence
allows public performance (for example CC0 / Creative Commons Zero). Keep
each file small (a 30-60 second loop at 128 kbps is a few hundred KB).
